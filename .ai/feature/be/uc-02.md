# UC-02 — Backend

## Cel
- Zwrócić listę plików przykładowych dostępnych w magazynie `examples`.
- Nie utrzymywać osobnego trwałego rejestru rekordów `examples`.

## Endpoint publiczny `FE -> BE`
- `GET /api/examples`

## Response
- `200 OK` -> `ExamplesListApiResponse`

```json
{
  "items": [
    {
      "name": "sudoku-20260325-184211.jpg",
      "contentType": "image/jpeg",
      "sizeBytes": 2481931,
      "storedAtUtc": "2026-03-25T18:42:11Z"
    },
    {
      "name": "sudoku-20260324-111203.png",
      "contentType": "image/png",
      "sizeBytes": 931221,
      "storedAtUtc": "2026-03-24T11:12:03Z"
    }
  ],
  "totalCount": 2
}
```

## Modele API wejściowe
- Brak modelu JSON wejściowego.

## Modele API wyjściowe
- `ExampleFileApiResponse`
  - `name: string`
  - `contentType: string`
  - `sizeBytes: number`
  - `storedAtUtc: string`
- `ExamplesListApiResponse`
  - `items: ExampleFileApiResponse[]`
  - `totalCount: number`

## DTO / wynik use case'u
- `ListExamplesQueryResultDto`
  - `items`
  - `totalCount`

## Zasady działania
- Backend skanuje katalog `examples/uploads`.
- `name` jest identyfikatorem zasobu przykładowego we wszystkich endpointach `UC-01..UC-04`.
- Lista powstaje na podstawie plików znajdujących się w magazynie, bez bazy danych i bez sidecarów JSON.
- `ML` nie bierze udziału w tym use case'ie.
