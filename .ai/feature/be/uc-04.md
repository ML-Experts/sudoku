# UC-04 — Backend

## Cel
- Udostępnić wybrany obraz przykładowy do podglądu.
- Orkiestrować dwa etapy preprocessingu bez trwałego zapisu wyników:
  - etap 1: wykrycie planszy i korekcja perspektywy,
  - etap 2: podział obrazu planszy na siatkę `9x9`.

## Endpointy publiczne `FE -> BE`
- `GET /api/examples/{name}`
- `PUT /api/examples/{name}/preprocess/board`
- `PUT /api/examples/preprocess/cells`

## Endpointy wewnętrzne `BE -> ML`
- `PUT /ml/preprocess/board`
- `PUT /ml/preprocess/cells`

## Request / response
### `GET /api/examples/{name}`
- `200 OK` -> `ImageApiResponse`

```json
{
  "mimeType": "image/jpeg",
  "base64": "/9j/4AAQSkZJRgABAQAAAQABAAD..."
}
```

### `PUT /api/examples/{name}/preprocess/board`
- Request body: brak
- `200 OK` -> `ImageApiResponse`

```json
{
  "mimeType": "image/png",
  "base64": "iVBORw0KGgoAAAANSUhEUgAA..."
}
```

### `PUT /api/examples/preprocess/cells`
- Request body: `ImageApiEntry`
- `200 OK` -> `CellsGridApiResponse`

```json
{
  "cells": [
    [
      {
        "mimeType": "image/png",
        "base64": "iVBORw0KGgoAAAANSUhEUgAA..."
      }
    ]
  ]
}
```

## Błędy API
- `400 Bad Request`
- `404 Not Found`
- `422 Unprocessable Content`
- `503 Service Unavailable`
- `504 Gateway Timeout`

```json
{
  "errorType": "board_not_detected",
  "message": "Nie wykryto planszy sudoku na obrazie."
}
```

## Modele API wejściowe
- `ImageApiEntry`
  - `mimeType: string`
  - `base64: string`

## Modele API wyjściowe
- `ImageApiResponse`
  - `mimeType: string`
  - `base64: string`
- `CellsGridApiResponse`
  - `cells: ImageApiResponse[9][9]`
- `ErrorApiResponse`
  - `errorType: string`
  - `message: string`

## DTO / wyniki use case'ów
- `GetExampleImageQueryResultDto`
  - `mimeType`
  - `base64`
- `PreprocessBoardCommandResultDto`
  - `mimeType`
  - `base64`
- `ExtractCellsCommandResultDto`
  - `cells`

## Zasady działania
- `GET /api/examples/{name}` zwraca obraz przykładowy jako `ImageApiResponse`, nie metadane rekordu.
- Wynik etapu 1 preprocessingu nie jest zapisywany na dysku; `BE` przekazuje go bezpośrednio do `FE`.
- Etap 2 przyjmuje `ImageApiEntry` z `FE`, ponieważ wynik etapu 1 nie jest utrwalany.
- Backend mapuje błędy z `ML` na spójne odpowiedzi HTTP z polami `errorType` i `message`.
- Publiczne i wewnętrzne payloady JSON używają `camelCase`.
