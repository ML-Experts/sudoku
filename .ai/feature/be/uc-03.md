# UC-03 — Backend

## Cel
- Zwrócić wybrany plik przykładowy jako binarny download.

## Endpoint publiczny `FE -> BE`
- `GET /api/examples/{name}/download`

## Response
- `200 OK`
- Body: binarny plik obrazu
- `Content-Type: image/jpeg` albo `image/png`
- `Content-Disposition: attachment; filename="{name}"`

## Błędy API
- `400 Bad Request`
- `404 Not Found`

```json
{
  "errorType": "example_not_found",
  "message": "Nie znaleziono przykładu o podanej nazwie."
}
```

## Modele API wejściowe
- Brak modelu JSON wejściowego.

## Modele API wyjściowe
- Sukces nie zwraca JSON, tylko plik binarny.
- `ErrorApiResponse`
  - `errorType: string`
  - `message: string`

## DTO / wynik use case'u
- `DownloadExampleQueryResultDto`
  - `name`
  - `contentType`
  - `stream`

## Zasady działania
- Backend odczytuje plik z magazynu `examples` po `name`.
- `name` musi zostać zwalidowane jako bezpieczny segment ścieżki.
- `ML` nie bierze udziału w tym use case'ie.
