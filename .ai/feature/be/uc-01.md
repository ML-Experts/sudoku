# UC-01 — Backend

## Cel
- Przyjąć plik obrazu Sudoku z `FE`, zwalidować go i zapisać w magazynie `examples`.
- Zwrócić do `FE` kanoniczną nazwę `name` oraz podstawowe metadane pliku.

## Endpoint publiczny `FE -> BE`
- `POST /api/examples`

## Request
- `Content-Type: multipart/form-data`
- Pole formularza: `file`

## Response
- `201 Created` -> `ExampleFileApiResponse`

```json
{
  "name": "sudoku-20260325-184211.jpg",
  "contentType": "image/jpeg",
  "sizeBytes": 2481931,
  "storedAtUtc": "2026-03-25T18:42:11Z"
}
```

## Błędy API
- `400 Bad Request`
- `409 Conflict`
- `413 Payload Too Large`
- `415 Unsupported Media Type`

```json
{
  "errorType": "unsupported_media_type",
  "message": "Dozwolone są wyłącznie pliki JPG i PNG."
}
```

## Modele API wejściowe
- Brak modelu JSON wejściowego; request używa `multipart/form-data`.

## Modele API wyjściowe
- `ExampleFileApiResponse`
  - `name: string`
  - `contentType: string`
  - `sizeBytes: number`
  - `storedAtUtc: string`
- `ErrorApiResponse`
  - `errorType: string`
  - `message: string`

## DTO / wynik use case'u
- `UploadExampleCommandResultDto`
  - `name`
  - `contentType`
  - `sizeBytes`
  - `storedAtUtc`

## Zasady działania
- Backend jest właścicielem publicznego API i magazynu `examples`.
- `name` jest kanoniczną nazwą pliku nadawaną przez `BE`.
- `BE` waliduje typ i rozmiar pliku przed zapisem.
- `ML` nie bierze udziału w tym use case'ie.
