# UC-03 — Frontend

## Cel
- Pozwolić użytkownikowi pobrać wybrany plik przykładowy.

## Endpoint `FE -> BE`
- `GET /api/examples/{name}/download`

## Response
- `200 OK`
- Body: binarny plik obrazu

## Modele API wejściowe
- Brak modelu JSON wejściowego.

## Modele API wyjściowe
- Brak modelu JSON po stronie sukcesu.
- `ErrorApiResponse` dla przypadków błędów.

## Zasady działania
- FE przekazuje do endpointu dokładnie `name` otrzymane z listy przykładów.
- Sukces powinien uruchomić natywne pobranie pliku w przeglądarce.
- W przypadku błędu FE pokazuje komunikat z `errorType` i `message`.
