# UC-13 — Frontend

## Cel
- Wyświetlić modal logowania administracyjnego po wejściu na stronę, ale dopuścić przejście dalej w ograniczonym trybie demo bez hasła.
- Uzyskać `JWT` z `BE`, zapisać go w kontekście sesji i dołączać do chronionych żądań administracyjnych.
- Rozdzielić publiczną ścieżkę demo na istniejących przykładach od funkcji administracyjnych.
- Obsłużyć błędne hasło, brak tokenu i wygaśnięcie sesji czytelnym komunikatem.

## Endpoint logowania `FE -> BE`
- `POST /api/auth/login`

## Publiczne żądania bez tokenu (tryb demo)
- `GET /api/examples`
- `GET /api/examples/{name}`
- `GET /api/examples/{name}/download`
- `PUT /api/examples/{name}/preprocess/board`
- `PUT /api/examples/preprocess/cells`
- `POST /api/examples/{name}/solve` lub równoważny endpoint solve dla wybranego przykładu z `UC-05`

## Chronione żądania `FE -> BE` (tryb administracyjny)
- `POST /api/examples`
- `GET /api/datasets/raw-candidates`
- `POST /api/datasets/processed`
- `GET /api/datasets/processed`
- `GET /api/models/registry`
- `POST /api/trainings`
- `GET /api/trainings`
- `GET /api/trainings/{runName}`
- `PUT /api/models/active`
- `SignalR /ws/trainings/{runName}`

## Kontrakty
### Logowanie administracyjne
- `POST /api/auth/login`
- Request body: `AdminLoginApiEntry`
- `200 OK` -> `AuthTokenApiResponse`

```json
{
  "password": "********"
}
```

```json
{
  "accessToken": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "tokenType": "Bearer",
  "expiresAtUtc": "2026-04-11T12:30:00Z"
}
```

### Nagłówek autoryzacyjny dla żądań chronionych

```http
Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
```

## Błędy API
- `401 Unauthorized` dla błędnego hasła, braku tokenu, tokenu niepoprawnego lub wygasłego.

```json
{
  "errorType": "invalid_credentials",
  "message": "Niepoprawne hasło administracyjne."
}
```

```json
{
  "errorType": "admin_token_expired",
  "message": "Sesja administracyjna wygasła. Zaloguj się ponownie."
}
```

## Modele API wejściowe
- `AdminLoginApiEntry`
  - `password: string`

## Modele API wyjściowe
- `AuthTokenApiResponse`
  - `accessToken: string`
  - `tokenType: string`
  - `expiresAtUtc: string` (`ISO-8601 UTC`)
- `ErrorApiResponse`
  - `errorType: string`
  - `message: string`

## Zasady działania
- FE wysyła do loginu wyłącznie pole `password`; nie pokazuje i nie przesyła `username` ani innych identyfikatorów.
- Modal logowania jest pokazywany po wejściu na stronę, ale użytkownik może z niego zrezygnować i przejść do ograniczonego trybu demo bez tokenu.
- Bez tokenu FE udostępnia wyłącznie publiczny flow pracy na istniejących przykładach: wybór przykładu, preprocessing, rozpoznanie i rozwiązanie sudoku z overlayem.
- `POST /api/examples` oraz widoki datasetów, treningów i modeli są ukryte albo zablokowane do czasu uzyskania poprawnego tokenu.
- Token jest przechowywany wyłącznie w kontekście sesji po stronie klienta i dokładany tylko do chronionych requestów.
- Po `401 Unauthorized` z powodu tokenu niepoprawnego lub wygasłego FE czyści lokalną sesję, wraca do ograniczonego trybu demo, ponownie otwiera modal i nie próbuje cichego odświeżania tokenu.
- FE nie przechowuje hasła po sukcesie logowania; po wygaśnięciu `JWT` użytkownik loguje się ponownie.
- FE może używać pola `expiresAtUtc` do wcześniejszego wygaszenia sesji bez czekania na pierwszy odrzucony request.
