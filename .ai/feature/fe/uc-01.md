# UC-01 — Frontend

## Cel
- Umożliwić użytkownikowi upload pliku Sudoku do biblioteki przykładów.

## Endpoint `FE -> BE`
- `POST /api/examples`

## Request
- `multipart/form-data`
- Pole formularza: `file`

## Response
- `201 Created` -> `ExampleFileApiResponse`

```json
{
  "name": "sudoku-20260325-184211.jpg",
  "contentType": "image/jpeg",
  "sizeBytes": 2481931,
  "storedAtUtc": "2026-03-25T18:42:11Z"
}
```

## Modele API wejściowe
- Brak modelu JSON wejściowego; request używa `multipart/form-data`.

## Modele API wyjściowe
- `ExampleFileApiResponse`
- `ErrorApiResponse`

## Zasady działania
- FE wysyła wyłącznie plik; kanoniczną nazwę `name` nadaje `BE`.
- Po sukcesie FE może odświeżyć listę przykładów albo dopisać nowy rekord lokalnie.
- W przypadku błędu FE pokazuje komunikat z `ErrorApiResponse`.
