# UC-12 — Frontend

## Cel
- Wykorzystać kandydatów datasetowych pobranych wcześniej w `UC-11`.
- Umożliwić użytkownikowi wybór jednego lub wielu źródeł, wskazanie splitów `train` / `val` / `test` albo trybu `mix`.
- Wysłać chronione żądanie przygotowania jednego zestawu `{name}.npz` i wyświetlić raport końcowy z licznościami, pustymi komórkami i odrzutami.
- Po sukcesie odświeżyć listę gotowych zestawów dostępnych później w `UC-06`.

## Znaczenie typów widocznych w UI
- `digit` oznacza logiczny rekord z `UC-11`, który technicznie odpowiada parze plików `*.idx3-ubyte` + `*.idx1-ubyte` o wspólnym prefiksie, np. `t10k`.
- `board` oznacza logiczny rekord z `UC-11`, który technicznie odpowiada jednemu katalogowi bezpośrednio pod `data/raw/boards`; jego `name` jest nazwą tego folderu.
- Dla `board` użytkownik nie wybiera osobno plików z katalogu; szczegóły par `<prefix>.jpg` + `<prefix>.dat`, również z dalszych podfolderów, są ukryte za rekordem logicznym.
- Wartość `0` w etykietach planszy wewnątrz `.dat` oznacza pustą komórkę, a nie cyfrę `0`; `FE` może to komunikować opisem pomocniczym, ale sam nie parsuje tych plików.
- Dla źródeł `digit` etykieta `0` może legalnie występować w secie używanym do baseline'u / pretrainingu; nie zmienia to faktu, że finalna inferencja Sudoku pozostaje semantycznie rozpoznawaniem cyfr `1..9` oraz pustych pól.

## Adresy / endpointy chronione `FE -> BE`
- `POST /api/datasets/processed`
- `GET /api/datasets/processed`

## Semantyka właściwości i reguły tworzenia
- `CreateProcessedDatasetApiEntry.name`:
  - wartość z pola tekstowego w formularzu `UC-12`,
  - użytkownik podaje nazwę logiczną zestawu bez `.npz`,
  - `FE` wysyła ją bez dodatkowego przetwarzania biznesowego poza podstawową walidacją formularza.
- `CreateProcessedDatasetApiEntry.sources`:
  - lista pozycji wybranych przez użytkownika z listy kandydatów pobranej w `UC-11`,
  - każdy element reprezentuje jedno źródło logiczne, a nie pojedynczy plik fizyczny.
- `SelectedRawDatasetSourceApiEntry.name`:
  - wartość pochodząca wprost z `GET /api/datasets/raw-candidates`,
  - `FE` nie powinno jej swobodnie edytować.
- `SelectedRawDatasetSourceApiEntry.type`:
  - wartość pochodząca wprost z `GET /api/datasets/raw-candidates`,
  - służy do pokazania użytkownikowi rodzaju źródła i jest odsyłana do `BE` do walidacji.
- `SelectedRawDatasetSourceApiEntry.splits`:
  - wynik wyboru użytkownika w UI,
  - `mix` oznacza automatyczny split po stronie serwera,
  - jawne `train` / `val` / `test` oznaczają partycje wskazane bezpośrednio przez użytkownika.
- `ProcessedDatasetApiResponse.fileName`:
  - techniczna nazwa wygenerowanego pliku wynikowego,
  - `FE` pokazuje ją informacyjnie, ale użytkownik nie wpisuje jej ręcznie.
- `ProcessedDatasetApiResponse.preprocessingProfile`:
  - nazwa profilu preprocessingu faktycznie użytego przez system,
  - jest to metadana read-only zwracana przez `BE`,
  - `FE` może ją wyświetlać, ale w `UC-12` MVP użytkownik jej nie ustawia.
- `ProcessedDatasetApiResponse.sampleCounts`:
  - sumaryczne liczności próbek zapisanych do końcowego `.npz`,
  - są to liczby po wykonaniu splitu i po odrzuceniu rekordów, które nie weszły do finalnego artefaktu.
- `ProcessedDatasetApiResponse.sourceReports`:
  - raport per źródło wejściowe,
  - pozwala UI pokazać, jak każde źródło wpłynęło na wynik końcowy.
- `ProcessedDatasetSourceReportApiResponse.processedSampleCount`:
  - liczba wszystkich próbek lub komórek technicznie przetworzonych dla danego źródła.
- `ProcessedDatasetSourceReportApiResponse.includedSampleCount`:
  - liczba próbek finalnie zapisanych do `.npz`.
- `ProcessedDatasetSourceReportApiResponse.emptyCellCount`:
  - liczba pustych komórek rozpoznanych dla źródła typu `board`,
  - odpowiada sytuacji, gdy w `.dat` wystąpiło `0`, które po stronie technicznej zostało potraktowane jako puste pole.
- `ProcessedDatasetSourceReportApiResponse.rejectedSampleCount`:
  - liczba próbek odrzuconych z powodu problemu jakościowego lub technicznego.
- `warnings`:
  - lista komunikatów, które `FE` powinno pokazać użytkownikowi bez traktowania ich jako twardego błędu,
  - ostrzeżenia uzupełniają raport końcowy i wyjaśniają różnice między licznościami folderów a `sampleCounts`.
- Metadane przygotowania datasetu, takie jak `preprocessingProfile`, `sampleCounts`, `sourceReports` i `warnings`, przychodzą do `FE` wyłącznie w odpowiedzi API; nie są odczytywane z zawartości pliku `.npz`.
- `preprocessingProfile`:
  - z perspektywy `FE` nie jest polem formularza, tylko nazwą użytej przez serwer recepty przetwarzania obrazu,
  - przykładowe `default-28x28-v1` oznacza profil prowadzący do wspólnego formatu wejściowego `28x28`,
  - jeśli `FE` pokazuje ten profil, powinien być prezentowany jako informacja diagnostyczna lub metadana zestawu.

## Błędy API
- `400 Bad Request` dla pustej nazwy zestawu, braku źródeł albo niepoprawnego wyboru splitów.
- `401 Unauthorized` dla braku lub wygaśnięcia tokenu administracyjnego.
- `404 Not Found` jeśli wybrane źródło zniknęło po wcześniejszym pobraniu listy z `UC-11`.
- `409 Conflict` jeśli zestaw `{name}.npz` już istnieje.
- `422 Unprocessable Content` jeśli źródło jest technicznie uszkodzone, katalog `board` ma złą strukturę albo nie udało się przygotować poprawnych próbek.
- `503 Service Unavailable` jeśli `ML` jest chwilowo niedostępny.
- `504 Gateway Timeout` jeśli przygotowanie datasetu przekroczy limit czasu po stronie `BE -> ML`.

```json
{
  "errorType": "invalid_dataset_split_selection",
  "message": "Pole splits dla pojedynczego źródła musi zawierać albo tylko mix, albo jeden lub wiele splitów train/val/test."
}
```

```json
{
  "errorType": "raw_dataset_type_mismatch",
  "message": "Źródło v1_training zostało wykryte jako board i nie może być przygotowane jako digit."
}
```

```json
{
  "errorType": "processed_dataset_name_conflict",
  "message": "Zestaw sudokuBoardsV1.npz już istnieje."
}
```

## Modele API wejściowe
- `CreateProcessedDatasetApiEntry`
  - `name: string`
  - `sources: SelectedRawDatasetSourceApiEntry[]`
- `SelectedRawDatasetSourceApiEntry`
  - `name: string`
  - `type: string` (`board` | `digit`)
  - `splits: string[]` (`train` | `val` | `test` | `mix`)

## Modele API wyjściowe
- `ProcessedDatasetApiResponse`
  - `name: string`
  - `fileName: string`
  - `preprocessingProfile: string`
  - `createdAtUtc: string` (`ISO-8601 UTC`)
  - `sources: SelectedRawDatasetSourceApiEntry[]`
  - `sampleCounts: SplitSampleCountsApiResponse`
  - `sourceReports: ProcessedDatasetSourceReportApiResponse[]`
  - `warnings: string[]`
- `ProcessedDatasetSourceReportApiResponse`
  - `name: string`
  - `type: string` (`board` | `digit`)
  - `processedSampleCount: number`
  - `includedSampleCount: number`
  - `emptyCellCount: number`
  - `rejectedSampleCount: number`
  - `warnings: string[]`
- `ProcessedDatasetListItemApiResponse`
  - `name: string`
  - `fileName: string`
  - `preprocessingProfile: string`
  - `createdAtUtc: string` (`ISO-8601 UTC`)
  - `sampleCounts: SplitSampleCountsApiResponse`
- `ProcessedDatasetsListApiResponse`
  - `items: ProcessedDatasetListItemApiResponse[]`
  - `totalCount: number`
- `SplitSampleCountsApiResponse`
  - `train: number`
  - `val: number`
  - `test: number`
- `ErrorApiResponse`
  - `errorType: string`
  - `message: string`

## Zasady działania
- `UC-12` startuje po pobraniu listy kandydatów z `UC-11`.
- Widok `UC-12` jest częścią strefy administracyjnej i wymaga tokenu z `UC-13`.
- `FE` pracuje wyłącznie na rekordach logicznych `name` + `type`; nie parsuje samodzielnie katalogów `board`, plików `.dat` ani plików IDX.
- Dla pojedynczego źródła wybór `mix` musi natychmiast wykluczać zaznaczenie `train` / `val` / `test`.
- `FE` powinien pozwolić wybrać wiele źródeł jednocześnie i wysłać je w jednym requestcie.
- Pole `name` reprezentuje logiczną nazwę zestawu; `BE` zapisuje finalny plik jako `{name}.npz`, więc UI nie musi wymuszać ręcznego dopisywania rozszerzenia.
- Dla typu `board` UI powinno pokazać czytelny opis pomocniczy, że źródło jest katalogiem w `boards`, a parowanie plików i skan podfolderów odbędzie się dopiero po stronie serwera.
- `FE` nie wysyła `preprocessingProfile` w requestcie publicznym `UC-12`; profil jest dobierany po stronie serwera i wraca dopiero jako metadana gotowego zestawu.
- Po sukcesie `FE` pokazuje `sampleCounts`, `sourceReports` i `warnings`, aby użytkownik widział nie tylko wynik końcowy, ale też liczbę pustych komórek i odrzuconych próbek per źródło.
- Po `503` albo `504` `FE` powinno pokazać komunikat techniczny o niedostępności lub przekroczeniu czasu, bez utraty formularza i wybranych wartości.
- Po `401 Unauthorized` `FE` czyści sesję administracyjną i wraca do logowania zgodnie z `UC-13`.
