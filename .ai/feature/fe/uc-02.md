# UC-02 — Frontend

## Cel
- Wyświetlić listę dostępnych przykładów Sudoku i udostępnić akcje `pobierz` oraz `przetwórz`.

## Endpoint `FE -> BE`
- `GET /api/examples`

## Response
- `200 OK` -> `ExamplesListApiResponse`

```json
{
  "items": [
    {
      "name": "sudoku-20260325-184211.jpg",
      "contentType": "image/jpeg",
      "sizeBytes": 2481931,
      "storedAtUtc": "2026-03-25T18:42:11Z"
    }
  ],
  "totalCount": 1
}
```

## Modele API wejściowe
- Brak modelu JSON wejściowego.

## Modele API wyjściowe
- `ExampleFileApiResponse`
- `ExamplesListApiResponse`

## Zasady działania
- FE traktuje `name` jako identyfikator zasobu przykładowego.
- Lista nie pokazuje trwałego statusu preprocessingu, bo wynik `UC-04` nie jest zapisywany.
- Akcja `pobierz` kieruje do `GET /api/examples/{name}/download`.
- Akcja `przetwórz` otwiera flow z `UC-04`.
